설비조합 최적화 시뮬레이션 가이드

건축물의 신재생에너지 의무설치비율(및 전력생산비율)을 충족하는 설비 조합을 자동 탐색하고, 사용자 요구도(비용·디자인·법적심의 등)에 따라 순위화하는 기능. 본 문서는 입력·기준조건·가중치·점수계산 전 과정을 설명한다.

0. 한눈에 보기 — 처리 흐름

  • 하드 제약(반드시 충족): 의무설치비율, 전력생산비율, 공간별 가용면적, 지열 최소의무
  • 소프트 목적(점수화): 초기비용·운영비·인센티브·디자인·시공성·의무근접·법규제약 (7개 요구도 차원)
  • 두 축은 섞지 않는다 — 제약은 후보 통과 여부, 목적은 통과 후보의 순위를 정한다.

  • 단위에너지사용량(kWh/㎡·yr): 의료시설 643.52 · 숙박시설 526.55 · 업무시설(공공) 371.66 · 교육연구시설 231.33
  • 원별보정계수ⓑ: BIPV 6.12 · SOFC 8.71 · PEMFC 2.20 · 지열 1.26 · PAFC 0.93 → §2.1 설비 데이터셋의 ⓑ와 정합
  • 의무비율: 공공 비주거 2026년 36%(2030년 40%) / 주거는 지역×인증등급(가~라)×연도, 자율·미시행(빈칸) 혼재

⚠ LIB_의무비율은 행이 많아(지역×주거구분×카테고리) 설정 모달에서 행 필터로 검색·편집한다. 본 가이드는 구조·조회 방식만 다루며 전체 값은 라이브러리 파일을 참조.

3. 최적화 기준 조건 (제약)

3.1 하드 제약 (반드시 충족 — 미충족 후보는 탈락)

  1. 의무설치비율: Σ(ⓒ·용량) / 연간에너지소요량 × 100 ≥ 의무설치비율기준
  2. 전력생산비율(선택): Σ(ⓕ·용량, 발전가능) / 연간예상전력소비량 × 100 ≥ 전력생산비율기준
  3. 공간별 면적: 공간별 Σ(ⓜ·용량) ≤ 가용면적 (옥상/외피/대지/기계실 각각)
  4. 지열 최소의무(선택): 옵션1 지열면적 ≥ 건축면적×비율% 또는 옵션2 지열생산량 ≥ 의무총량×비율%

경계해 부동소수 오차 허용(eps=1e-6) — 예: 9.99999%를 10% 충족으로 인정.

3.2 소프트 목적 (점수화 — §5)

7개 요구도 차원. 하드 제약을 통과한 후보들 사이의 상대 순위만 결정한다.

4. 알고리즘 흐름 (optimizer.js)

4.1 조합 생성 — 구조 다양화 (generateCombinations)

조합 = PV옵션 × 연료전지분기 × 건물설비 부분집합

  • PV: [없음, 수평PV, BAPV, BIPV] 중 택1
  • 대용량 연료전지(PAFC·SOFC발전): 없음 + (종류 × 1~최대기수), 1종 배타 — *전력 목표 있을 때만*
  • 건물설비(지열·PEMFC·SOFC건물): 부분집합 전수 열거(공집합 포함)

부분집합 열거 이유: LP가 최소비용 단일설비로 수렴해 조합이 붕괴하는 것을 막고, "지열-only/PV+지열/PEMFC-only" 등 구조적으로 다른 후보를 확보해 다양한 요구도를 대표하게 한다.

4.2 용량 LP — 5개 목적함수 (solveCapacity)

각 조합을 5개 목적함수로 각각 풀어 서로 다른 용량 배분을 유도한다(objCoeff).

목적방향목적계수(설비당)
cost최소장비비 ⓓ
benefit최대순익 ⓛ
incentive최대등급점수(ⓝ ZEB)
design최대(역방향 디자인훼손ⓞ + 외부공간ⓟ)/2
constraint최대9요인 평균 제약 적합도(1−강도)
  • 고정설비(연료전지 기수) 기여를 제약 우변에서 차감 → 잔여 제약으로 연속설비 용량을 푼다.
  • 최대화 목적은 의무 충족 + 과설치 상한 20%(OVER설치=1.2)를 둬 무한 설치를 막는다.
  • 연속 LP 해는 스냅단위 정수배로 올림(snapToUnit) — 의무 충족 유지.

4.3 필터링·중복 제거

  • LP infeasible 제거 → 법적규제 재검증(eps) → 스냅으로 늘어난 면적 재검증
  • 동일 설비:용량 조합 통합(dedup)

4.4 지열 의무 옵션 비교 (해당 시)

지열 의무비율 > 0이면 옵션1(면적)·옵션2(생산량)을 각각 최적화하고, 1위 종합점수가 높은 쪽을 추천한다(서울 "면적 또는 생산량" 관계).

5. 가중치 적용 & 점수 계산 (핵심)

5.1 요구도 → 가중치 환산 (deriveWeights)

각 요구도 등급을 요구도점수(매우높음5·높음4·보통3·낮음2·매우낮음1)로 바꾸고, 합이 1이 되도록 정규화한다.

raw_k = 요구도점수[요구도_k]          (k = 7개 차원)
w_k   = raw_k / Σ raw                 (Σ w = 1)

예: 의무근접=높음(4), 나머지 6개=보통(3) → raw=[3,3,3,3,3,4,3]=22 → w(의무근접)=4/22≈0.18, 나머지 각 ≈0.136.

5.2 6개 목표값 산출 (targetCalculator.js)

조합의 채택 설비(items = [{설비, 용량}])로부터:

목표값산식
초기비용Σ ⓓ·용량
운영순익Σ ⓛ·용량
설치면적공간별 Σ ⓜ·용량
법적규제의무비율·전력생산비율 + 충족 여부
정성(ZEB·디자인·시공성·인센티브)용량가중 "좋음점수" 평균 (아래)
제약9요인 프로파일 + 요인가중 적합도 (§5.3)

정성 점수 규칙

  • 등급점수: 매우높음5 … 매우낮음1
  • 역방향 지표(디자인훼손ⓞ·외부공간ⓟ·공사기간ⓠ·난이도ⓡ): 낮을수록 좋음 → 좋음점수 = (최대+최소) − 등급점수 = 6 − 등급점수
  • ZEB = 용량가중평균( 등급점수(ⓝ) )
  • 디자인 = 용량가중평균( (좋음ⓞ + 좋음ⓟ)/2 ) → 경관계수 보정
  • 시공성 = 용량가중평균( (좋음ⓠ + 좋음ⓡ)/2 )
  • 인센티브 = ZEB (proxy — 정밀 용적률% 매핑은 ECO2 연계 시 예정)

경관계수 보정 (디자인 전용)

계수      = 1 + 경관민감도(지자체) × 경관영향(세부형식)
보정디자인 = gmax − (gmax − 기본디자인) × 계수      (gmax=등급점수 최댓값, [gmin,gmax] 클램프)

→ 경관영향=0(지열·연료전지)은 어느 지자체에서도 계수=1(불변). 강한 지자체일수록 노출형 PV·BAPV의 디자인 패널티↑.

5.3 법규제약 — 9요인 프로파일 & 적합도

매트릭스를 평균 1개로 붕괴시키지 않고 요인별로 산출한다.

요인별 점수(f)   = 용량가중평균( 등급점수(매트릭스[설비][f]) )   (1~5, 높을수록 제약↑)
요인별 적합도(f) = (gmax − 점수(f)) / (gmax − gmin)               (0~1, 제약 낮을수록 1)
종합 적합도      = Σ_f [ 제약요인가중치(f) × 적합도(f) ] / Σ_f 제약요인가중치(f)
  • 기본은 9요인 균등 가중. 입지·건물유형에 따라 특정 요인(예: 도심=경관, 데이터센터=소음)을 가중할 수 있다.
  • 법규제약사용=false이면 적합도=1(중립)로 순위에 영향 없음. 프로파일은 표시용으로 항상 산출.

5.4 정규화 (7차원 → 0~1)

차원정규화 방식방향
초기비용조합집합 min-max낮을수록 1
운영순익조합집합 min-max높을수록 1
인센티브고정척도 (v−gmin)/gspan높을수록 1
디자인고정척도높을수록 1
시공성고정척도높을수록 1
의무근접min(1, 의무기준/실제비율)딱 맞을수록 1(과충족 0↓)
법규제약종합 적합도(0~1)제약 낮을수록 1

비용·순익은 절대범위가 가변이라 min-max, 정성·제약은 척도가 고정(등급점수)이라 고정척도를 쓴다. 고정척도는 미미한 raw 차이가 0↔1로 과장되는 것을 막는다. (min-max는 전 조합 동일값이면 중립 1.0 처리)

5.5 종합 점수 & 순위

종합점수 = Σ_k  w_k × n_k        (k = 7개 차원, 0~1)
  • 점수 내림차순 정렬 → rank 부여. 화면 점수는 ×100.

5.6 강점 태그 · 챔피언 (tagDimensions)

가중치와 무관하게 "이 조합이 어떤 요구도를 잘 만족하는가"를 표시.

rel = (정규화값 − min) / (max − min)        (차원별)
rel ≥ 0.85  → 해당 차원 태그 부여
최댓값 조합  → 챔피언(★)
차별성 없음(span < 0.05) → 태그 생략

6. 결과 표시 (optimizeUI.render)

  • 표시 대상: 종합점수 상위 10개 + 차원별 챔피언(가중치 낮은 요구도의 대표 조합도 노출)
  • 카드 구성: 순위/점수/최적 배지 · 강점 태그칩(★챔피언) · 설비별 용량 막대 · 목표값(초기비용·연간순익·의무비율·전력생산) · 정성 막대(디자인·시공성·ZEB·심의적합) · 9요인 제약 프로파일(확장) · AI 설명 버튼
  • 배너: 경관 보정 적용 안내(지자체 민감도), 지열 의무 옵션1/옵션2 비교 추천
  • AI 설명: 조합별 추천 근거를 Gemini로 생성(설비 장단점·목표값 기반)
  • 보고서 출력: 조건표 + 순위표 + AI설명을 A4 보고서로 출력

7. 설정 편집 (⚙ 설정 모달, settingsUI.js)

좌측 상단 ⚙ 설정에서 모든 값을 편집(localStorage 오버라이드, 저장 즉시 다음 계산 반영, 기본값 복원·JSON 내보내기/가져오기 지원).

  • 최적화 가중치·상수: 경관/법규제약 on·off, 연료전지 기수, 외피층고, 요구도점수·등급점수, 제약 요인별 가중치(9칸)
  • 라이브러리 테이블: 설비최적화(ⓐ~ⓡ), 요구도, 전력원단위, 경관민감도·영향, 법적심의 제약 매트릭스(9요인 5등급 드롭다운), 계산 공용(신재생계수·지역계수·단위에너지·의무비율)

8. 한계·주의 (도메인 검토 필요)

  1. 전력 원단위 잠정값 — LIB_전력원단위는 실측·공인통계 확정 전(특히 데이터센터). 전력생산비율 신뢰도에 직접 영향.
  2. 제약 매트릭스 정성판정 — 경관·일조 등급은 공식문서 명문 임계치가 적어 도메인 추론 비중이 큼. 등급·요인가중치는 검토·조정 대상.
  3. 경관민감도 미조사 지자체 — 비수도권 도(道)는 잠정 0.5(중). 추가 조사 시 갱신.
  4. 인센티브 proxy — 현재 ZEB기여도 기반. 정밀 용적률% 매핑은 ECO2 연계(P6) 시.
  5. 단순 가중합 순위 — 완전한 Pareto front는 미구현(차원별 챔피언으로 부분 보완).
  6. PAFC 별표10 — 미등재 가정(ⓑ=0.93). 정식 등재 확인 시 값 갱신.

9. 빠른 사용 절차

  1. 사업정보(대지위치·연면적 등) 입력 → Output1/2 계산 (의무비율·에너지소요량 자동 연동)
  2. 「설비조합 최적화」 탭 진입 → 법적규제 기준 확인, (선택) 전력생산비율·가용면적 입력
  3. 건물유형·사업형태 선택 → 표준 요구도 자동 반영 → 필요 시 7차원 요구도 조정
  4. 최적 조합 탐색 실행 → 순위 카드·태그·9요인 프로파일 확인
  5. 관심 조합 AI 설명 생성 → 보고서 출력(PDF/Word/HTML)
  6. 값 조정이 필요하면 ⚙ 설정에서 라이브러리·가중치 편집 후 재실행
