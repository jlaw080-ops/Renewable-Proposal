# UI/UX 전면 개편 설계 — Technical Teal "엔지니어링 검토 콘솔"

- **무엇을**: 신재생에너지 검토 앱의 스킨(색·타이포·컴포넌트)을 ENERGINNO 사내 디자인 토큰(Theme T)으로 전면 교체하고, 종합 리뷰에서 확인된 결함 15건을 함께 수정한다.
- **왜**: 현행 디자인은 범용 SaaS 룩(파랑 CTA)이라 정체성이 없고, 대비 미달(hint 2.3:1 등)·모달 포커스 이탈 등 접근성 결함이 실측으로 확인됐다.
- **결론**: 잉크 네이비 + 틸 액센트의 사내 정렬 스킨 + 다크 나브 시그니처 + 구조 보수. 화면 구성·계산 엔진은 유지한다.

작성일: 2026-08-09 · 승인: 사용자 (방향 ①안 선택, 상세 설계 승인)

## 3. 타이포

- **NanumSquareNeo** 400/700/800을 `next/font/local` **자체 호스팅**으로 도입 (CDN 런타임 의존 금지 — 기존 SRI 정책과 일관). woff2를 `app/fonts/`에 두고 `--font-sans`에 연결. 폴백: Apple SD Gothic Neo → Malgun Gothic.
- 헤딩 800 (페이지 타이틀·카드 타이틀은 700), 본문 400. 헤딩 `line-height: 1.25`, `word-break: keep-all`.
- 본문 14px 유지(전문가 밀도 도구). **모바일(≤767px) 입력·textarea·select는 16px** — iOS 자동 확대 방지.
- 수치·표: IBM Plex Mono + `tabular-nums` 유지.

## 4. 컴포넌트 스킨

| 컴포넌트 | 변경 |
|---|---|
| Button | `primary`=네이비 채움 단일화, **`brand` 변형 삭제**(호출부 `variant="brand"` → `primary` 치환). ghost=흰 배경+헤어라인. danger 유지(#C44545 텍스트). `:focus-visible` 2px 틸, `:active` scale(0.96) |
| Badge | 판정 배지에 기호 병행: 만족 ✓ · 불만족 ✕ · 해당없음 – (색 단독 의존 제거). 신규 틴트 쌍 적용 |
| Field/Select | `.field__input:focus { outline:none }` **제거** → 전역 `:focus-visible` 2px 틸 링으로 통일. 보더 색 변화는 유지해도 무방 |
| 반복 행 라벨 | `info` 용도 행·`ScenarioEditor` 시스템 행의 2행 이후: `visually-hidden` 라벨 부여 (`용도 (n행)` 형식) |
| Stepper | **3상태 재설계**: 완료(틸 ✓ 원) · 현재(흰 채움 + 좌측 틸 활성 바) · 미완(dim 외곽 원). 완료 판정은 저장 데이터 존재 기준(1=input1 필수값, 2=input2 시나리오, 3=input3, 4=review/보고서 생성 이력). 색 도트 4종 폐기. 모바일 가로 스테퍼에도 동일 상태 표기 |
| Modal | **포커스 트랩**(Tab 순환) + 열림 시 내부 첫 포커스 이동 + 닫힘 시 트리거 복귀 + 배경 `inert` + `overscroll-behavior: contain`. 공통 컴포넌트 1곳 수정으로 5개 모달 전부 해소 |
| Toast | `tone:"fail"`은 자동 소멸 없이 닫기 버튼으로 수동 닫힘, 나머지는 3초 유지 |
| Table | 헤더 배경 `--bg-card-inner`, 잉크 톤 정렬. 구조 변경 없음 |
| 파일 입력 | 보고서 표지 업로드를 Button 스타일 트리거 + `visually-hidden` input으로 교체 |

## 5. 구조 보수

- **다크 나브(시그니처)**: 데스크톱 좌측 고정 네이비 패널(`--nav-bg`), 프로젝트명·뒤로가기 흰 계열. 1023px 이하는 다크 상단 바로 전환(기존 반응형 로직·잘림 페이드 단서 승계, 다크 배경에 맞게 마스크 색 조정).
- **콘텐츠 중앙 정렬**: `.ws__content`에 `margin-inline: auto` — 1440px 초과에서 좌측 쏠림 해소.
- **판정 밴드**: `Output2Panel` 상단을 전폭 밴드로 재구성 — 설치비율 큰 숫자 + 의무비율 + 판정 배지 한 줄. 기존 KPI 3분할은 밴드 아래 상세(총에너지·생산량)로 축소. `dt/dd`는 `<dl>`로 감싸 유효 마크업화.
- **② 검토 계산 카드**: 상태 문구(부족 안내·엔진 오류)를 카드 헤더 영역으로 통합, 정상 상태에서 빈 본문 카드를 렌더하지 않는다.
- **대시보드 카드 열기**: `<button onClick={router.push}>` → `<Link href>` (새 탭·중간클릭 지원).
- **문구 교체**: "3경로 동기" → "주소·지도·직접 선택 연동" / "규모등급(카테고리)" → "규모등급". 그 외 개발 용어 발견 시 동일 원칙(사용자 언어)으로 교체.
- **범위 밖(명시)**: `legacy/` 무수정 원칙 유지 · 설정 모달 내부 legacy UI(`settingsUI.js` 생성분)는 CSS 변수 승계로 자동 추종만(개별 재설계 없음) · A4 보고서 출력물(`buildStyledReport`) 스타일 불변 · 화면 플로우(4단계 구성) 불변 · 계산 엔진(`engine/`·`public/`) 무수정.
