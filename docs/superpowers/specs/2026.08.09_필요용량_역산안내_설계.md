# 의무비율 충족 필요 용량 역산 안내 설계

- **무엇을**: 시나리오의 각 시스템 행에서 에너지원·형식을 고르면, 의무비율을 채우는 데 필요한 용량(kW)을 즉시 보여준다. 다른 행이 일부를 채우고 있으면 **잔여 필요 용량**을 보여준다.
- **왜**: 지금은 용량을 감으로 넣고 결과 비율을 보고 다시 고치는 시행착오가 필요하다. 필요 용량을 먼저 알면 한 번에 맞출 수 있다.
- **결론**: 엔진의 비율 계산식을 역산해 행별 필요 용량을 표시한다. 자동 입력은 하지 않는다(사용자가 판단해 입력).

작성일: 2026-08-09 · 요청: 사용자

## 1. 역산 공식

엔진(`engine/output2Calculator.js`) 계산식:

```
생산량_i = 적용용량_i × 단위에너지생산량_i × 원별보정계수_i
비율     = Σ생산량 / 총에너지사용량 × 100
만족     = 비율 ≥ 의무비율
```

이를 행 `i`에 대해 역산한다:

```
목표생산량   = 총에너지사용량 × 의무비율 / 100
확보생산량_i = Σ(생산량_j)  단, j ≠ i          ← 자기 행은 제외
잔여생산량_i = max(0, 목표생산량 − 확보생산량_i)
필요용량_i   = ceil( 잔여생산량_i / (단위에너지생산량_i × 원별보정계수_i) )
```

- **자기 행을 제외**하는 것이 핵심이다. 그래서 하나의 공식이 두 상황을 모두 커버한다:
  - 첫 시스템(다른 행 없음) → 확보 0 → 전체 필요 용량
  - 용량을 부족하게 넣고 시스템 추가 → 새 행에서 확보 = 앞 행 생산량 → **잔여** 필요 용량
- **올림(ceil, 정수 kW)** — 내림하면 그 값을 입력해도 의무비율에 미달한다(`≥` 조건). 정수 kW는 설비 용량 단위로도 실용적이며 오차는 1kW 미만 초과.

## 2. 표시 규칙

각 시스템 행 아래 메타 줄(`.se__meta`)에 이어서 표시한다.

| 상황 | 표시 |
|---|---|
| 다른 행 기여 없음 | `의무비율 충족 필요 용량 1,647 kW` |
| 다른 행이 일부 기여 | `잔여 필요 용량 812 kW` (문구로 "잔여"임을 명시) |
| 잔여 0 이하 | `✓ 의무비율 충족 — 추가 용량 불필요` |
| 계산 불가 | 표시하지 않음 |

**계산 불가 조건** (표시 생략):
- 계산 결과 없음(① 사업정보 미완성) — 총에너지사용량을 모름
- `의무비율`이 `null` (해당없음 지역·조건)
- 총에너지사용량 ≤ 0
- 해당 행의 `단위에너지생산량 × 원별보정계수` ≤ 0 (형식 미선택 등)

## 3. 구현 방식

- 신규 순수 모듈 `lib/capacityHint.js` (TDD) — `requiredCapacity({ 총에너지사용량, 의무비율, systems, index })` → `{목표생산량, 확보생산량, 잔여생산량, 필요용량, 충족} | null`
- `ScenarioEditor`에 `target` prop 추가: `{ 총에너지사용량, 의무비율 } | null`. calc 페이지가 `result`에서 파생해 전달(`result.output1.총예상에너지사용량`, `result.output2[0]?.의무비율`)
- 자동 입력·자동 보정은 하지 않는다 — 안내만 한다(사용자의 설계 판단 영역)
