# ALT별 구성·판정 짝 배치 설계

- **무엇을**: 검토 계산 화면에서 시나리오(ALT)와 그 판정 결과를 **ALT 단위로 같은 행에 나란히** 배치하고, ALT마다 하나의 묶음으로 구분한다.
- **왜**: 지금은 좌열에 모든 ALT 구성이, 우열에 모든 판정이 따로 쌓여 있어 어느 결과가 어느 ALT인지 눈으로 맞춰야 하고, 좌우 블록 높이도 어긋난다.
- **결론**: 그리드 행 하나 = ALT 하나(좌: 구성 / 우: 판정). 같은 행이므로 높이가 자동으로 같아진다.

작성일: 2026-08-09 · 요청: 사용자

## 1. 배치

```
▶ ≥1280px — ALT별 2열 짝
┌─ ALT-1 구성 ──────────┐ ┌─ ALT-1 판정 ──────────┐
│ 에너지원/형식/용량 …      │ │ 9.1% 의무 14.5% ✕불만족 │
│ 필요 용량 안내 …          │ │ 생산량·설비별 표          │
└───────────────────┘ └───────────────────┘
        (ALT 묶음 사이 간격 크게)
┌─ ALT-2 구성 ──────────┐ ┌─ ALT-2 판정 ──────────┐
│ …                    │ │ …                    │
└───────────────────┘ └───────────────────┘
                [+ ALT 추가]

▶ <1280px — 1열, ALT별로 구성 → 판정 순서로 인접
```

- 좌우 셀은 **같은 그리드 행**이므로 높이가 자동 정렬된다(`align-items: stretch` + 카드 `height: 100%`)
- ALT 묶음 사이 간격(`--sp-6`)을 묶음 내부 간격(`--sp-4`)보다 크게 둬 그룹 경계를 만든다
- 좁은 화면에서도 개선된다: 기존에는 "모든 구성 → 모든 판정" 순서였으나, 이제 ALT-1 구성 바로 아래 ALT-1 판정이 온다

## 2. 카드 구성

| 위치 | 제목 | 내용 |
|---|---|---|
| 바깥(전폭) | `시나리오와 판정 (ALT별)` | 짝 행들 + `+ ALT 추가` |
| 좌 inner | `{ALT-id} 구성` | 기존 시나리오 편집 UI(시스템 추가·ALT 삭제 액션 포함) |
| 우 inner | `{ALT-id} 판정` | 기존 `Output2Panel` |

- 우측 카드 제목이 ALT id를 갖게 되므로 `Output2Panel`의 판정 밴드 안 id(`verdict__id`)는 중복이 된다 → `hideId` prop(기본 false)으로 숨긴다. 기존 호출부 동작은 불변
- 결과가 아직 없는 ALT(계산 전·ALT 추가 직후)는 우측에 안내 문구만 표시: `시나리오를 구성하면 판정 결과가 표시됩니다`

## 3. 기존 구조와의 관계

- 이 배치는 **③ 2열 배치 설계(2026.08.09_검토계산_2열배치)를 대체**한다. "좌=모든 입력 / 우=모든 결과" 열 구조는 폐기하고, 열 분할을 ALT 단위로 내린다
- 유지되는 것: Output1 최상단 전폭 카드, 판정 요약 고정 바(`VerdictSticky`), 중첩 스크롤 금지(페이지 스크롤 하나)
- 폐기되는 CSS: `.calc__cols`, `.calc__col`, `.calc__col--input`, `.calc__col--result` (사용처 없어짐 → 삭제)

## 4. 매칭 규칙

- ALT ↔ 결과 매칭은 **id 기준**: `result.output2.find(a => a.id === scenario.id)`
- 엔진(`calcOutput2`)이 `scenarios`를 순서대로 매핑하며 `id`를 보존하므로 id 매칭이 안전하다. 인덱스 매칭은 ALT 삭제·추가 시 어긋날 수 있어 쓰지 않는다
- 매칭 실패 시(리렌더 시점 차이) 우측은 안내 문구로 대체 — 잘못된 결과를 다른 ALT에 붙이지 않는다
