# 전면 개편 마스터플랜

> **For agentic workers:** 이 문서는 전체 Phase의 범위를 고정하는 인덱스다. 실행은 Phase별 상세 계획 문서로 한다. Phase 상세 계획은 직전 Phase 완료 체크포인트에서 작성한다 (superpowers:writing-plans 사용).
> 원본 스펙: `docs/superpowers/specs/2026.07.26_전면개편_설계문서.md`

**Goal:** Vanilla JS 단일 페이지 앱을 Next.js 기반 상용 SaaS 수준 웹앱으로 전면 개편하되, 검증된 계산 엔진은 무수정 재사용한다.

**Architecture:** Next.js(App Router, JavaScript)를 레포 루트에 스캐폴드. 런타임 엔진 모듈(`data/`·`optimize/`·`vendor/`·`settings/` 등)은 `public/`으로 이동해 스크립트 로드(window 전역 유지), ES 모듈인 `engine/`은 루트에 남겨 직접 import. UI는 100% 신규 작성. 서버리스 함수는 Next.js Route Handler로 포팅.

**Tech Stack:** Next.js(App Router)·React·JavaScript(TS 미도입)·plain CSS(디자인 토큰)·네이버 지도 JS SDK·Gemini(기존 프록시 포팅)·javascript-lp-solver(기존)·localStorage

## Global Constraints (전 Phase 공통)

- **엔진 무수정**: `engine/` `public/optimize/` `public/data/` `public/vendor/` `public/settings/settingsStore.js` 내용 변경 금지 (git mv 이동만 허용). 유일한 예외: `recommendPrompt.js` (Phase 4에서 "비교→추천" 프롬프트 수정 명시 허용)
- **계산 동일성**: 모든 Phase에서 `node verify/verify_all.js public` 및 `node verify/verify_output12.js public` 결과가 Phase 0 스냅샷(`verify/snapshots/`)과 일치해야 함
- **작업 브랜치**: `revamp/next` — `main` 머지는 Phase 6에서만 (프로덕션 보호, Vercel Preview로 확인)
- **언어·스타일**: JavaScript(TS 금지), plain CSS + CSS 커스텀 프로퍼티 토큰(Tailwind 금지), 컴포넌트 PascalCase, 파일 200~400줄 지향
- **API 키**: 코드 하드코딩 금지 — `.env.local`(gitignored) + Vercel 환경변수만. 기존 `GEMINI_API_KEY` `NCP_CLIENT_ID` `NCP_CLIENT_SECRET` + 신규 `DATA_GO_KR_KEY` `JUSO_CONFIRM_KEY`
- **커밋**: 태스크 단위, conventional commits(`feat:` `chore:` `test:` …)
- **응답 언어**: UI 문구·문서 전부 한국어
