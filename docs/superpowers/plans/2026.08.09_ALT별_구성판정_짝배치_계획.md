# ALT별 구성·판정 짝 배치 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 검토 계산 화면에서 ALT별로 좌(구성)·우(판정)를 같은 그리드 행에 짝지어, 높이가 같고 ALT 묶음이 구분되게 한다.

**Architecture:** `ScenarioEditor`가 결과(`results`)를 받아 ALT별 짝 행을 렌더한다. 페이지는 기존 2열 컨테이너를 제거하고 전폭 카드 하나로 감싼다. 엔진·스키마 무변경.

**Tech Stack:** Next.js(App Router, JS), Vanilla CSS(기존 토큰), `node --test`, Playwright(msedge).

**스펙:** `docs/superpowers/specs/2026.08.09_ALT별_구성판정_짝배치_설계.md`

- [ ] **Step 3: ALT 렌더를 짝 행으로 감싸기**

현재 `{scenarios.map((sc, si) => (` 의 반환값은 `<Card key={sc.id} title={sc.id} inner actions={…}>…</Card>` 하나다. 이를 **짝 행으로 감싸고 우측 셀을 추가**한다. 기존 좌측 카드 내용(actions·`.se__systems`·시스템 행·메타·힌트)은 **한 글자도 바꾸지 않고** 그대로 옮긴다. 바꾸는 것은 (a) 감싸는 `<section className="se__pair">` 추가, (b) 좌측 카드 title을 `` `${sc.id} 구성` `` 으로, (c) `key`를 `section`으로 이동, (d) 우측 셀 추가:

```jsx
      {scenarios.map((sc, si) => {
        const altResult = results?.find(a => a.id === sc.id) ?? null;   // id 매칭 — 인덱스 매칭 금지
        return (
          <section className="se__pair" key={sc.id}>
            <Card title={`${sc.id} 구성`} inner actions={
              /* ↓ 기존 actions 블록 그대로 */
            }>
              {/* ↓ 기존 .se__systems 블록 그대로 */}
            </Card>

            <Card title={`${sc.id} 판정`} inner>
              {altResult
                ? <Output2Panel alt={altResult} hideId />
                : <p className="se__hint">시나리오를 구성하면 판정 결과가 표시됩니다.</p>}
            </Card>
          </section>
        );
      })}
```

`+ ALT 추가` 버튼은 `scenarios.map(...)` 바깥, 기존 위치(짝 행들 다음)에 그대로 둔다.

- [ ] **Step 4: scenarioEditor.css — 짝 행 규칙 추가**

`.se` 규칙의 `gap`을 ALT 묶음 간격으로 키우고 짝 행 규칙을 추가한다. 파일 상단 `.se { … }` 를 다음으로 교체:

```css
/* ALT 묶음 사이 간격(--sp-6)을 묶음 내부(--sp-4)보다 크게 — 그룹 경계를 공백으로 만든다 */
.se { display: flex; flex-direction: column; gap: var(--sp-6); align-items: flex-start; }
```

파일 끝(모바일 미디어 쿼리 앞)에 추가:

```css
/* ALT 짝 행: 좌 구성 · 우 판정. 같은 그리드 행이라 높이가 자동으로 같아진다 */
.se__pair { display: grid; gap: var(--sp-4); width: 100%; }
.se__pair > * { min-width: 0; }
.se__pair > .card { height: 100%; }
@media (min-width: 1280px) {
  .se__pair { grid-template-columns: minmax(0, 1fr) minmax(0, 1.1fr); align-items: stretch; }
}
```

주의: `.se > * { width: 100% }`·`.se > button { width: auto }` 기존 규칙은 그대로 둔다(짝 행이 전폭을 차지하고 버튼만 내용 폭을 갖는다).
